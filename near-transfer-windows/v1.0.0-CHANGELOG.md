# Near Transfer for Windows 1.0.0

- Bản phát hành Windows đầu tiên, tương thích Windows 7 SP1 trở lên, 32-bit và 64-bit.
- Gửi và nhận file hoặc một tin nhắn văn bản với Near Transfer trên Android qua mạng nội bộ.
- Tìm thiết bị trong LAN, kết nối bằng địa chỉ IPv4 và lưu thiết bị thường dùng.
- Yêu cầu người nhận chấp thuận trước khi nhận file; hiển thị tiến độ và kết quả gửi/nhận.
- Dùng .NET Framework 4.8 đã cài trên máy; bộ cài tải runtime từ Microsoft nếu còn thiếu.

## Giới hạn đã biết

- Kiểm tra giao thức đã chạy thành công trên Linux; bộ cài và giao diện đã được kiểm tra thủ công trên Windows và xác nhận hoạt động. Phiên bản Windows và kiến trúc máy kiểm thử chưa được ghi nhận.
- Bộ cài chưa được ký mã, nên Windows SmartScreen có thể cảnh báo.
- Giao thức dùng HTTP không mã hóa; chỉ truyền dữ liệu trên mạng nội bộ đáng tin cậy.
