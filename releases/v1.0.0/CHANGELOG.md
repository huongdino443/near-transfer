# Near Transfer 1.0.0

Initial public release.

- Discover nearby devices on the same Wi-Fi network.
- Send up to 20 files in one batch.
- Let the receiver review and accept the file list before transfer starts.
- Send one text message separately from file and media transfers.
- Save received files to `Download/Near Transfer/`.
- Open received files with another installed app through a read-only content URI.
- Support legacy Android devices from Android 2.3 (API 9).
