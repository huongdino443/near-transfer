# Release artifacts

The latest official release is **Near Transfer 1.0.2**, published as one
cross-platform release containing both Android and Windows artifacts.

| Version | Android APK | Windows installer | SHA-256 |
|---|---|---|---|
| Near Transfer 1.0.2 | [`Near-Transfer-1.0.2.apk`](v1.0.2/Near-Transfer-1.0.2.apk) | [`v1.0.2-NearTransfer-Windows-Setup.exe`](v1.0.2/v1.0.2-NearTransfer-Windows-Setup.exe) | [`SHA256SUMS.txt`](v1.0.2/SHA256SUMS.txt) |

The v1.0.2 folder contains the signed Android APK, Windows installer, release
notes, and checksums. The Android APK is release-signed. The Windows installer
is not code-signed and may trigger a SmartScreen warning. Unsigned APKs,
private signing keys, and passwords are not distributed.

Older release snapshots remain available under their respective version
folders, while the official GitHub Release page is the authoritative download
location.
